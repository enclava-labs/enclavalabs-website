01 · enclava.dev · confidential application platformLaunching now

enclava.dev, the confidential application platform.

Push a container, get a confidential application. enclava.dev runs any Linux container inside a hardware trusted execution environment on AMD SEV-SNP — web apps, databases, signing workers, inference servers — with the operator outside the trust boundary.

Every deploy publishes an attestation that pins the exact image, so whoever sends it data can check what is running first.

A deploy ends in evidence.

enclava deploy
$ enclava deploy myapp
→ resolving image digest…        ok
→ verifying signature…           ok
→ allocating TEE (SEV-SNP)…      ok
▸ TEE attested
▸ https://myapp.enclava.dev live
measurement sha256:9f2a…c41d ✓ policy SEV-SNP · v1.55 ✓ launch amd-signed ✓

The attestation is public. Checking it does not involve us.

  1. 1Deploy.One declarative file — image, resources, volumes, domain — and one command. The workflow of any modern platform.
  2. 2Seal.Memory is encrypted in use. Secrets are encrypted on your machine and opened only inside the TEE, volumes use keys only the TEE holds, and TLS ends inside it.
  3. 3Prove.Each deploy emits a statement signed by the hardware that describes exactly which code is running. Anyone can verify it before sending data.

02 · confidential inference

Inference that is checked first.

When a prompt has to leave the building, it should only go somewhere that has proved what it is running. This is the layer Enclava calls. It works without Enclava too.

Local models and confidential inference work together. Keep what runs well on your own hardware there, and send the rest only to a model that has proved where it runs.

Fail-closed Rust SDK. A request is sent only after the route satisfies an explicit attestation policy. Verifies Intel TDX, AMD SEV-SNP and NVIDIA GPU evidence.

03 · Enclava · enclava.ai

Enclava, the company brain.

One place that knows what the company knows. Enclava connects the systems where work already happens, keeps the structure of every document it reads, and lets people and assistants ask across all of it.

Ask where a project stands and the answer is assembled from the issues, the threads and the planning doc — each claim with its source.

A citation points at the page, table, clause or section.

Master services agreement · page 12
7.1
7.2Either party may terminate on ninety days' written notice.
7.3
“The notice period is ninety days [1]” [1] page 12 · clause 7.2

Locators come from the parsed document. Where the parser found none, none is shown.

  1. 1Connect.Slack, Teams, GitHub, GitLab, Jira, Linear, Notion and Google Drive sync into knowledge collections. Uploads work too: PDF, DOCX, spreadsheets, HTML, EPUB and scanned images.
  2. 2Understand.Documents are parsed into ordered blocks and clauses can be kept whole. Search is hybrid — dense and keyword, fused — with query rewrite and section selection on top.
  3. 3Answer.Chat and search across collections. Assistants carry their own instructions, tools connect over MCP to approved servers only, and all of it sits behind an OpenAI-compatible API.
